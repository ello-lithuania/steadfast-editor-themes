# Steadfast editor themes

Four light themes with warm paper backgrounds and one accent colour, made for long reading and writing sessions. Text colours meet WCAG AA contrast on the background.

- **Steadfast Green**: colours taken from [KokybiskaSvetaine.lt](https://kokybiskasvetaine.lt/).
- **Plum Evening**: colours taken from [Vestuvių metinės](https://vestuviumetines.lt/).
- **Forest and Brass**: colours taken from [Dovanos su vardu](https://dovanasuvardu.lt/).
- **Powder Blue Morning**: colours taken from [Krikštynų dovana](https://krikstynudovana.lt/).

| Editor | Folder | Install |
|---|---|---|
| Vim and Neovim | [`vim/`](vim) | Copy `vim/colors/*.vim` to `~/.vim/colors/`, then `:colorscheme steadfast-green` |
| JetBrains IDEs | [`jetbrains/`](jetbrains) | Install from the JetBrains Marketplace |
| VS Code and compatible editors | [`vscode/`](vscode) | Install from Open VSX |

The same colours are also available for Typora and Sublime Text.
